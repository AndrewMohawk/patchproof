ongoing commits/pushes. Created `AndrewMohawk/patchproof` privately. This is not
permission to enter the competition, accept terms, publish source/video, expose
a service or spend. `owner-decisions.json` records owner decisions. The owner
subsequently authorized **$25 total**, now recorded in `budget.json`: up to $5
smoke and $20 pilot, with no evaluation/hosting expansion. No expiry was
specified. No credits are claimed. This cap does not bypass account or gate checks.

passed before any task-state updates. The initial commit preserves that package.
The ZIP was neither opened nor extracted. No home-directory secrets or private
repositories were searched. Existing authenticated `gh` was used for the

## Contract v1 preparation

Use TypeScript on the installed Node 25.5.0 runtime with exact npm locks.
Zod schemas are the runtime and TypeScript contract source. Provider interfaces
are our internal interfaces, not invented Nebius SDK signatures. Provider/model
IDs, billing rates, image digest and entitlements stay null until verified.

The current catalogue has only a non-executable `contract-smoke` schema fixture.
It is not one of the evaluation tasks. Mock runs make no model/sandbox calls,
produce no patch and finish `needs_review`; every API/export/UI shows mock mode
and `competitionReady: false`. Lifecycle events record actual mock-handler
transitions and do not imply inference or acceptance-check execution.

The small loopback page is a contract inspection harness, not the T10 product.
No arbitrary repositories, code, commands or URLs are accepted. The mock service
uses in-memory state; restarting loses runs, explicitly documented pending T08.
Do not use this service as the production coordinator or expose it publicly.

Every real-provider command reports unmet gates and exits nonzero. Export/replay
of mock files checks integrity only and explicitly cannot reproduce a patch
verdict. No placeholder command returns a successful real-provider result.

An open-source license remains an owner choice; contribution rights have been
confirmed. npm metadata is `UNLICENSED`; third-party package notices are retained.
Public publication cannot proceed until the project license is selected.

Mock exports are immutable local files. Verification reports whether it used a
local reference, an explicitly supplied digest or just the export's self-digest.
None establishes authenticated provenance. Browser downloads can be placed in
`artifacts/<run-id>.json` and checked with the command/digest shown on the page.
The full T08 clean-workspace patch replay and publisher protection remain undone.
