# PatchProof fixture corpus v2

This corpus contains 60 original benign Python maintenance tasks grouped into 12 small synthetic repositories. Twelve separately launched AI author contexts each designed one repository and five tasks from the same public schema and instructions. An independent evaluator reviewed every requirement, start, gold implementation and check. Repository ownership determines the frozen split: four development repositories (20 tasks), two calibration repositories (10 tasks), and six final repositories (30 tasks).

Only development and calibration task definitions belong in this public tree. All gold implementations, final task definitions, sealed checks, detailed review notes and container outputs remain in the private evaluator workspace. `split-manifest.json` exposes only split identities and byte digests for private artifacts. `author-provenance.json` binds each accepted revision to its author, shared instructions, correction history and independent validation receipt. The launch ledger records the coordinator's actual fresh-context launches; it is not a separately authenticated platform audit.

Validation runs each gold implementation, faulty start and repeated gold against its checks in fresh bounded local containers. Every task must reject its intended faulty start and meaningful benign negative controls. Additional independently chosen reviewer semantic and mutation controls supplement the author checks. This prepares oracles; it supplies no repair-model score, provider latency or provider cost result. Original submissions and unsuccessful preparation attempts are retained privately.

Inputs, outputs and mutation checks use JSON. Finite examples cannot prove universal behavior, Python object identity or distinctions lost during JSON transport. Requirement labels identify a check's primary purpose; joint return-and-mutation checks do not exclusively locate a defect. Minimal empty/None boundary calls can recur. Independent author contexts can still choose related algorithm families; the shared model population, synthetic domains and function-call format limit generalization. These are neither sampled upstream projects nor independently authored human repositories.

All fixture material is original project-owned output dedicated under CC0-1.0. No third-party repository or dataset was copied. Version 1 remains preserved by immutable Git references and its separate private evaluator workspace. Prior evidence belongs to its pinned version and is not reinterpreted as a v2 result, including evidence using the stable public demo task ID.
