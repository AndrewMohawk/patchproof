# Prospective independent fixture corpus

Status: authoring, independent review and local validation in progress. The
default product catalog still uses v1. No scored repair-model episode or final
result has been observed. This directory contains coordinator provenance and
aggregate evidence only, never final check definitions or gold source.

The PRD asks for twelve independently authored fixture repositories. The v1
suite had twelve logical groups from one authoring process. Separate oracle
review did not establish separate repository authorship. V2 addresses that
specific gap with twelve original AI author jobs, each launched with
`fork_turns: none`, each assigned one cohesive repository with five tasks. Four
repositories are development, two calibration and six final: 20/10/30 tasks.

Authors may read only the common instructions/schemas, their assigned job and
their own workspace. They receive no old corpus, sibling implementation, gold,
repair feedback or scored result. A shared public interface for the existing
demonstration task is specified in repo01's job; its new implementation and
checks are independently authored. JSON transport and check-observation limits
are shared contract facts. Later clarifications and all revisions are retained.

The separate evaluator reviews definitions and requirement mappings before
executing Python in bounded local containers. Acceptance requires corrected
gold to pass, the intended faulty start to fail, repeated gold checks to agree,
and benign incorrect alternatives to be rejected. Failures and earlier revisions
remain evidence, including source-only findings that were never executed.
These preparation checks are not a repair-model experiment.

[`author-jobs.json`](author-jobs.json) records the coordinator's actual launch
facts and submitted hashes. It is not an independently authenticated platform
log. Private submissions, author rationale, gold and sealed cases live under
the separate `patchproof-evaluation-v2` workspace. Shared OS ownership makes
author context separation procedural; candidate execution uses the existing
restricted container interface. Production evaluator account separation remains
a further gate.

V2 establishes separately authored synthetic repositories, not independently
sampled upstream projects, human authors or independent model populations.
Finite JSON checks do not prove universal correctness or object identity.
Common author models and fixture conventions still limit external validity.
No improvement claim follows from corpus preparation alone.

[`v1-preservation.json`](v1-preservation.json) binds the original 35 public
fixture, manifest, license and evidence files to immutable source `4e0116d` and
exact byte hashes. The original private evaluator workspace is retained. Replay
old exports with their recorded full source checkout; changing a fixture in a
new default catalog must never rewrite the interpretation of an old run.
